# Fuentes de Ingreso de ORION NOVA TECHNOLOGIES

## ORION NOVA TECHNOLOGIES

Las fuentes de ingreso de **ORION NOVA TECHNOLOGIES** provienen principalmente del desarrollo de soluciones tecnológicas personalizadas, servicios profesionales, mantenimiento, soporte técnico y planes recurrentes.

La empresa combinará ingresos por proyectos individuales con ingresos mensuales, buscando estabilidad financiera y relaciones comerciales de largo plazo.

---

## 2. Ingresos por mantenimiento y soporte

Después de entregar un proyecto, Orion Nova Technologies ofrecerá planes de mantenimiento para generar ingresos recurrentes.

Los planes podrán incluir:

* Corrección de errores.
* Actualización de contenido.
* Copias de seguridad.
* Monitoreo de servidores.
* Actualizaciones de seguridad.
* Soporte remoto.
* Optimización del sistema.
* Horas mensuales de asistencia.
* Informes de funcionamiento.
* Atención prioritaria.

Los precios podrán comenzar desde **$150.000 COP mensuales** y llegar hasta **$2.000.000 COP mensuales o más**, dependiendo del sistema y del nivel de atención contratado.

## 12. Forma de pago de los proyectos

Para proteger el flujo de caja, se propone la siguiente modalidad:

| Etapa                       | Porcentaje |
| --------------------------- | ---------: |
| Anticipo para comenzar      |       50 % |
| Entrega de avance funcional |       30 % |
| Entrega final               |       20 % |

En proyectos grandes, los pagos podrán dividirse por fases o entregables.

No se iniciará un proyecto sin:

* Propuesta aprobada.
* Alcance definido.
* Contrato o aceptación escrita.
* Anticipo confirmado.
* Cronograma establecido.

Los porcentajes podrán ajustarse según el tamaño y riesgo del proyecto.

## 14. Registro y control de ingresos

Cada ingreso deberá registrarse con la siguiente información:

| Campo                | Descripción                           |
| -------------------- | ------------------------------------- |
| Fecha                | Día en el que se recibió el dinero    |
| Cliente              | Persona o empresa que realizó el pago |
| Servicio             | Trabajo contratado                    |
| Número de cotización | Documento relacionado                 |
| Valor total          | Precio completo del proyecto          |
| Pago recibido        | Dinero efectivamente ingresado        |
| Saldo pendiente      | Valor que falta por pagar             |
| Medio de pago        | Transferencia, efectivo u otro        |
| Estado               | Pendiente, parcial o pagado           |
| Observaciones        | Información adicional                 |

Los ingresos personales del propietario deberán mantenerse separados de los ingresos de Orion Nova Technologies.

Los **$4.000.000 COP registrados como activos iniciales no se consideran ingresos por ventas**, porque representan recursos o bienes vinculados a la empresa.

## Conclusión

Orion Nova Technologies tendrá diferentes fuentes de ingreso basadas en proyectos tecnológicos, servicios profesionales, mantenimiento, consultoría, capacitación, automatización y productos propios.

La estrategia será combinar proyectos de pago único con planes mensuales y servicios recurrentes. Esto permitirá mejorar el flujo de caja, fortalecer las relaciones con los clientes y construir una empresa rentable y sostenible.
