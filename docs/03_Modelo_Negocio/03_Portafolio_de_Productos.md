# Introducción

El presente documento describe el portafolio oficial de productos de ORION NOVA Technologies.

Cada producto forma parte del Ecosistema ORION, una plataforma tecnológica diseñada para integrar Inteligencia Artificial, Computación en la Nube, Internet de las Cosas (IoT), Robótica, Ciberseguridad y Analítica de Datos, ofreciendo soluciones innovadoras para personas, empresas e instituciones.

Todos los productos compartirán una arquitectura modular, escalable, interoperable y segura, permitiendo su evolución y adaptación a diferentes necesidades del mercado.

---

# Objetivo

Definir el conjunto de productos estratégicos de ORION NOVA Technologies, describiendo su propósito, funcionalidades principales, público objetivo y beneficios.

# ORION Core

## Descripción

ORION Core será el núcleo tecnológico del ecosistema.

Centralizará la autenticación, administración de usuarios, permisos, configuraciones, servicios compartidos e integración entre todos los productos.

## Funcionalidades

- Gestión de usuarios.
- Gestión de roles.
- Autenticación.
- API Gateway.
- Configuración centralizada.
- Integración entre plataformas.

## Público objetivo

- Empresas
- Instituciones
- Desarrolladores
